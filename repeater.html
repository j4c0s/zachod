Przekaźnik – Wzmacniacz Sygnału dla Sąsiadów

Przystępny poradnik: Jak skonfigurować stację bazową (przekaźnik), która powiększy zasięg lokalnej, bezpłatnej sieci dla całej okolicy.
📅 Harmonogram wprowadzania regionów na Zachodzie:
Abyśmy mogli bezpiecznie i bez zakłóceń sprawdzić działanie systemu, wprowadzamy regiony stopniowo:
  • Do 31 sierpnia: Każdy właściciel stacji ustawia regiony w swoich przekaźnikach (repeaterach).
  • Od 1 września: Zaczynamy aktywnie korzystać ze "scopes" (zasięgów regionalnych) na kanałach w telefonach.
Dzięki temu damy sobie czas, aby sprawdzić, które przekaźniki wymagają jeszcze poprawy konfiguracji przed pełnym startem!
⚡ Łatwa aktualizacja:
Aby wszystko działało w pełni stabilnie i sprawnie, zalecamy wgranie oprogramowania w wersji minimum 1.16. Oficjalne paczki znajdziesz na meshcore.io. Zoptymalizowane i przyjazne dla energii wersje ściągniesz bezpośrednio z IoTThinks GitHub Releases.
💻 Praca z wierszem poleceń (CLI):
Gdy wpisujesz komendę w okienku konfiguracyjnym, zawsze poczekaj chwilę na radosną informację zwrotną o poprawnym zapisaniu ustawienia.

1. Zasilanie i przygotowanie fizyczne

  • Zasilanie i słońce: Nasz przekaźnik świetnie sprawdza się na zasilaniu solarnym! Upewnij się, że panel słoneczny i mały akumulator bez problemu utrzymają stację przy życiu w nocy i pochmurne dni.
  • Szumy tła (Noise Floor): Czysty sygnał to podstawa. Jeśli montujesz stację blisko dużych anten telekomunikacyjnych i sygnał ma zakłócenia, świetnym, polecanym rozwiązaniem jest zastosowanie prostego filtra szczelinowego (cavity filter).
  • Nazewnictwo: Unikajmy technicznych i chłodnych przedrostków takich jak "RPT". Wystarczy piękna, opisowa nazwa, która wskaże sąsiadom Twoją lokalizację i pomoże im ustawić antenę kierunkową (np. Sulechow_Wsch czy Wroclaw_Krzyki_Zachod).

2. Kim jesteś? (Tożsamość i kontakt)

Wpisz swoje imię, pseudonim lub znak, aby sąsiedzi z okolicy wiedzieli, komu dziękować za świetny zasięg:

set owner.info "TWOJE_IMIE_LUB_NICK"

3. Wysyłanie statusu stacji (Adverty)

📣 Ogłoszenie Lokalne

Jak często stacja ma mówić "jestem tu" bezpośrednim sąsiadom (zalecamy raz na 4 godziny, czyli 240 minut):

set advert.interval 240

🌍 Ogłoszenie Globalne (Flood)

Jak często stacja ma wysyłać swój status dalej w Polskę (wystarczy raz na 23 godziny):

set flood.advert.interval 23

4. Synchronizacja zegara

Aby przekaźnik zawsze wiedział, która jest godzina i sprawnie układał rozmowy:

clock sync

Gdyby zegar z jakiegoś powodu pokazywał błędny czas i nie chciał się dogadać z siecią, możesz go zresetować tą prostą komendą:

clkreboot

5. Regiony i zasięgi rozmów

Nasz przekaźnik potrafi mądrze decydować, które wiadomości przesyłać dalej, aby nie zapychać sieci niepotrzebnymi sprawami z drugiego końca kraju. Dodanie regionów do konfiguracji przekaźnika jest w pełni bezpieczne, nie koliduje z ogólnymi wiadomościami, a odblokowuje poprawne i szybkie przesyłanie spraw lokalnych.

🌍 Złota zasada sąsiedzkich regionów:
Dodawaj do swojej stacji wyłącznie regiony, które odpowiadają Twojemu województwu, miastu oraz główne kanały krajowe (jak pl czy zachod). Wszystkie szczegóły znajdziesz na stronie Regiony i Scopes.

Oto proste komendy, którymi nauczysz swój przekaźnik nowych regionów:

# Dodanie nowego regionu do stacji:
region put [nazwa_regionu]
# Pozwolenie na przekazywanie wiadomości z tego regionu:
region allowf [nazwa_regionu]
# Przypisanie stacji do domyślnego regionu Twojej okolicy:
set default.region [nazwa_regionu]
# Trwałe zapisanie ustawień w stacji i ponowne uruchomienie:
region save
reboot

6. Optymalizacja i bezpieczeństwo (CLI)

  • Włączenie przesyłania (Repeat Mode): Mówi stacji, by chętnie przekazywała głosy sąsiadów dalej. 
    set repeat.mode on
  • Zasada równego głosu (Duty Cycle): Ogranicza czas ciągłego nadawania do 10%, dbając o to, by pasmo było wolne dla każdego i zgodne z europejskimi standardami. 
    set dutycycle 10
  • Wykrywanie pętli (Loop Detect): Chroni naszą wspólną sieć przed przypadkowym zapętleniem się i "zakrzyczeniem" pasma. 
    set loop.detect minimal
  • Lepsze potwierdzenia (Multiple ACKs): Poprawia odbieranie wiadomości przy bardzo słabym zasięgu. 
    set multi.acks 1
  • Otwartość dla sąsiadów: Pozostawiając hasło gościa puste, pozwalasz innym na bezpieczny podgląd tego, jak świetnie działa Twój przekaźnik. 
    set guest.password ""

7. Grzeczność w eterze: Opóźnienia nadawania (txdelay)

Aby nasze urządzenia nie wchodziły sobie w słowo i nie zagłuszały się nawzajem, stosujemy prostą zasadę: im wyżej i lepiej położony jest nasz przekaźnik (czyli im więcej słyszy urządzeń), tym dłuższą chwilę powinien odczekać przed przesłaniem wiadomości dalej. Pozwala to mniejszym, domowym urządzeniom wypowiedzieć się jako pierwsze.

Wysokość stacji Gdzie się znajduje? Zalecane opóźnienia komend
🌳 WYSOKI / MASZT
Słyszy ponad 15 sąsiadów		 Wysokie wieże, dachy wieżowców, wzgórza. 
set txdelay 1.5
set direct.txdelay 1.0
set rxdelay 3
🏠 DACH DOMU
Słyszy 5 do 15 sąsiadów		 Dach domu jednorodzinnego, wysokie drzewo, strych. 
set txdelay 0.8
set direct.txdelay 0.4
set rxdelay 3
🪴 DOM / BALKON
Słyszy poniżej 5 sąsiadów		 Balkon, parapet, wewnątrz pokoju. 
set txdelay 0.3
set direct.txdelay 0.1
set rxdelay 3

8. Inne przydatne komendy

set path.hash.mode 2
set flood.max 64
set flood.max.unscoped 8
powersaving on
📋 Przyjazna Checklista: Klikaj po kolei przyciski "kopiuj", wprowadzaj je do swojej stacji, a system sam zaznaczy gotowe kroki kolorem zielonym!
1. Tożsamość sąsiedzka
Ustaw swoje imię lub nick, by sąsiedzi znali właściciela przekaźnika.
set owner.info "TWOJE_IMIE_LUB_NICK"
2. Rozgłaszanie lokalne
Ustawianie statusu lokalnego (zalecamy co 4 godziny, czyli 240 minut).
set advert.interval 240
3. Rozgłaszanie globalne
Jak często przesyłać status dalej w Polskę (raz na 23 godziny).
set flood.advert.interval 23
4. Zgodność czasu
Zsynchronizuj czas systemowy przekaźnika z siecią.
clock sync
5. Reset czasu (w razie kłopotów)
Komenda restartująca wewnętrzny zegar, jeśli się zgubił.
clkreboot
6. Regiony: europe
Wprowadź ogólnoeuropejski obszar łączności.
region put europe
7. Regiony: pl
Wprowadź ogólnopolski obszar łączności.
region put pl
8. Regiony: zachod
Wprowadź makroregion Polski Zachodniej do pamięci stacji.
region put zachod
9. Dodaj region swojego województwa i miasta
Dodaj region odpowiedni dla Twojego województwa (np. pl-ds dla Dolnego Śląska, pl-lb dla Lubuskiego lub wlkp dla Wielkopolski) oraz miasta (np. wro dla Wrocławia). Wszystkie szczegóły są na stronie Regiony i Scopes.
region put pl-ds
region put pl-lb
region put wlkp
region put wro
10. Powiązanie domyślnego regionu stacji
Ustaw domyślny region dla komunikatów własnych stacji (np. pl).
set default.region pl
11. Trwały zapis regionów
Zapisz bezpiecznie wszystkie dodane regiony w pamięci stacji.
region save
12. Ponowne uruchomienie
Zrestartuj przekaźnik, by wdrożyć całą nową konfigurację.
reboot
13. Przesyłanie głosów: Repeat Mode
Włącz tryb powtarzania rozmów w eterze.
set repeat.mode on
14. Dobre maniery: Duty Cycle
Ograniczenie czasu nadawania do bezpiecznych 10% w zgodzie z normami europejskimi.
set dutycycle 10
15. Bezpieczeństwo sieci: Loop Detect
Włącz wykrywanie pętli, by uchronić sieć przed burzami pakietów.
set loop.detect minimal
16. Stabilność zasięgu: Multiple ACKs
Włącz podwójne potwierdzenia dla lepszego zasięgu na granicach sieci.
set multi.acks 1
17. Otwartość: Puste hasło gościa
Pozostaw puste hasło gościa dla podglądu statusu przez sąsiadów.
set guest.password ""
18. Opóźnienie nadawania (txdelay)
Wybierz profil wysokości swojej stacji, by automatycznie dobrać komendę poniżej:
set txdelay 1.5
19. Opóźnienie bezpośrednie (direct.txdelay)
Ustawienie opóźnienia dla sygnałów wysyłanych bezpośrednio.
set direct.txdelay 1.0
20. Bezpieczna przerwa (rxdelay)
Zapobiega wcinaniu się stacji w trwające jeszcze słuchanie sygnału.
set rxdelay 3
21. Układanie tras: Hash Mode
Ustaw zalecany i nowoczesny sposób podpisywania tras pakietów (tryb 2).
set path.hash.mode 2
22. Maksymalne przekazywanie globalne
Ograniczenie maksymalnej drogi sygnałów w całej sieci.
set flood.max 64
23. Ograniczenie ruchu bez regionu
Limitowanie przekazywania sygnałów, które nie mają wybranego regionu.
set flood.max.unscoped 8
24. Przyjazne oszczędzanie energii
Włącz tryb oszczędzania energii, niezwykle ważny na zasilaniu bateryjnym i solarnym.
powersaving on
