Instrukcja dla Obserwatora (Observera)

Przewodnik krok po kroku po konfiguracji bezgłośnego punktu nasłuchowego sieci MeshCore na bazie ESP32.
ℹ️ Opracowano na podstawie dokumentacji Let's Mesh:
Oficjalny wątek techniczny i szczegóły oprogramowania znajdziesz na Forum Let's Mesh.

1. Instalacja oprogramowania

Wgraj natywne oprogramowanie dedykowane dla Observera bezpośrednio z oficjalnego serwisu Let's Mesh Analyzer:

  • Narzędzie instalacyjne online: Flash Native Observer Firmware
  • Po pomyślnym wgraniu oprogramowania zaleca się konfigurację podstawowych parametrów radiowych przy pomocy oficjalnego konfiguratora online na stronie meshcore.io.

2. Podstawowa konfiguracja Wi-Fi i parametrów stacji

Połącz się z konsolą szeregową (CLI) urządzenia i wprowadź następujące komendy w celu konfiguracji Wi-Fi, lokalizacji IATA i kontaktów telemetrycznych:

set wifi.ssid "NAZWA_TWOJEGO_WIFI"
set wifi.pwd "HASLO_DO_WIFI"
set mqtt.iata "KOD_IATA"

* Kody IATA określają przybliżoną pozycję geograficzną Twojego węzła (np. WRO, IEG). Listę dostępnych kodów i mapę sprawdzisz pod adresem: Let's Mesh IATA Codes Map. 

set mqtt.owner "TWÓJ_PUBLICZNY_KLUCZ_COMPANIONA"
set mqtt.email "TWÓJ_ADRES_EMAIL"
set bridge.source rx
reboot

3. Dodatkowy serwer MQTT (Lokalny Analizator)

W celu wsparcia lokalnego, krajowego polskiego analizatora, możesz przekierować odbierane pakiety również na serwer meshcorekrk.cma.pl:

set mqtt.server "mqtt.meshcorekrk.cma.pl"
set mqtt.port 1883
set mqtt.username "meshcore"
set mqtt.password "meshcore"

4. Pełna lista komend GET w tym oprogramowaniu

Jeżeli chcesz sprawdzić stan poszczególnych zmiennych lub przeprowadzić szczegółową diagnostykę, do Twojej dyspozycji są następujące komendy odpytujące:

Komenda CLI Opis działania w języku polskim
get mqtt.origin Pobiera nazwę pochodzenia (identyfikator urządzenia).
get mqtt.iata Zwraca skonfigurowany kod IATA.
get mqtt.status Sprawdza status wysyłania wiadomości stanu (on/off).
get mqtt.packets Pobiera ustawienie przesyłu standardowych pakietów (on/off).
get mqtt.raw Pobiera ustawienie przesyłu pakietów w formacie raw (on/off).
get mqtt.tx Sprawdza status raportowania pakietów nadawanych TX (on/off).
get mqtt.interval Zwraca interwał publikacji statusu MQTT (w milisekundach).
get mqtt.server Zwraca aktualny adres serwera MQTT.
get mqtt.port Zwraca numer portu serwera MQTT.
get mqtt.username Pobiera nazwę użytkownika MQTT.
get mqtt.password Pobiera skonfigurowane hasło do serwera MQTT.
get mqtt.analyzer.us Zwraca stan przesyłu do serwera US Let's Mesh Analyzer (on/off).
get mqtt.analyzer.eu Zwraca stan przesyłu do serwera EU Let's Mesh Analyzer (on/off).
