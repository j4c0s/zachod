Obserwator – Cichy Pomocnik i Diagnostyka Sieci

Przewodnik krok po kroku: Jak w prosty sposób uruchomić bezgłośny punkt nasłuchowy (Obserwatora) na bazie modułu ESP32.
ℹ️ Opracowano przy wsparciu społeczności Let's Mesh:
Więcej szczegółów oraz oficjalny wątek techniczny dotyczący tego oprogramowania znajdziesz na przyjaznym Forum Let's Mesh.

Kim jest Obserwator?

Obserwator to bezgłośny, mały, domowy pomocnik sieci. Nie nadaje wiadomości i nie zakłóca spokoju — zamiast tego "słucha" ruchu w eterze i pozwala innym użytkownikom oraz stacjom na diagnostykę stanu sieci. Bezpiecznie przekazuje informacje o jakości połączeń przez domowe Wi-Fi bezpośrednio do map i systemów telemetrycznych, dzięki czemu cała społeczność wie, czy sieć działa prawidłowo.

1. Łatwa instalacja oprogramowania

Instalacja jest w pełni automatyczna i bezpieczna. Wystarczy podłączyć moduł ESP32 kablem USB do komputera i kliknąć przycisk na poniższej stronie:

  • Szybka instalacja online: Instaluj oprogramowanie Obserwatora →
  • Po pomyślnym wgraniu oprogramowania zaleca się konfigurację parametrów radiowych przy pomocy oficjalnego konfiguratora online na stronie meshcore.io.

2. Podłączenie do domowego Wi-Fi

Połącz się ze stacją przez wiersz poleceń (CLI) i wpisz poniższe komendy, by dać Obserwatorowi dostęp do Internetu oraz określić jego lokalizację:

set wifi.ssid "NAZWA_TWOJEGO_WIFI"
set wifi.pwd "HASLO_DO_WIFI"
set mqtt.iata "KOD_IATA"

* Kod IATA określa przybliżoną okolicę Twojego węzła (np. WRO dla Wrocławia, IEG dla Zielonej Góry). Listę kodów IATA oraz piękną mapę znajdziesz pod adresem: Mapa kodów IATA Let's Mesh. 

set mqtt.owner "TWOJ_KLUCZ_COMPANIONA"
set mqtt.email "TWOJ_ADRES_EMAIL"
set bridge.source rx
reboot

3. Wsparcie dla lokalnego Analizatora (MQTT)

Aby wspierać naszą polską społeczność oraz ułatwić lokalną diagnostykę sąsiadom, możesz skierować dane do serwera meshcorekrk.cma.pl:

set mqtt.server "mqtt.meshcorekrk.cma.pl"
set mqtt.port 1883
set mqtt.username "meshcore"
set mqtt.password "meshcore"

4. Pełna lista przyjaznych komend odpytujących (GET)

Gdy zechcesz sprawdzić status stacji lub zobaczyć jej parametry, możesz skorzystać z następujących poleceń diagnostycznych:

Komenda diagnostyczna Co ona pokazuje?
get mqtt.origin Pobiera unikalny identyfikator Twojego Obserwatora.
get mqtt.iata Pokazuje przypisany kod lokalizacji IATA.
get mqtt.status Sprawdza, czy stacja wysyła swój status sprawności (on/off).
get mqtt.packets Sprawdza status przekazywania zwykłych pakietów (on/off).
get mqtt.raw Pokazuje, czy wysyłamy pakiety w oryginalnej formie surowej (on/off).
get mqtt.tx Sprawdza, czy raportujemy wysyłane pakiety (on/off).
get mqtt.interval Zwraca czas (w milisekundach) pomiędzy wysyłaniem statusu stacji.
get mqtt.server Pokazuje adres serwera, na który wysyłamy status.
get mqtt.port Zwraca numer portu serwera telemetrycznego.
get mqtt.username Zwraca nazwę użytkownika połączenia telemetrycznego.
get mqtt.password Zwraca skonfigurowane hasło połączenia.
get mqtt.analyzer.us Sprawdza wysyłanie do amerykańskiego serwera Let's Mesh (on/off).
get mqtt.analyzer.eu Sprawdza wysyłanie do europejskiego serwera Let's Mesh (on/off).
